**Scope fit:** Independent claims cover: (1) a quality-determination method measuring expression of VMO1 and/or THBS2, designating cells as "non-therapy-grade" when these markers are present; (2) an extended marker panel (CGNL1, CD166, CD56, CD44, CD10) distinguishing therapy-grade CECs (CGNL1+/CD166+/CD56+/CD44-/CD10-) from non-therapy-grade populations; (3) selection/sorting methods using these markers to enrich cultures for native-like CECs for clinical transplantation; (4) composition claims for therapy-grade CEC cultures meeting specified marker thresholds (~85-90% quality cells); and (5) a computer-implemented/machine-learning quality-assessment method for automated CEC classification. Fits the new biomarker/RNA-seq/molecular-characterization inclusion criterion added to scope 2026-09-08.
