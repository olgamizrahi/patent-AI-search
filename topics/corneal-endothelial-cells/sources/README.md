## Method note

patentscope.wipo.int returned 503/403 errors from within this environment
(general internet access and freepatentsonline.com were reachable). All
Google Patents bibliographic and legal-status data above was retrieved by
fetching the same patents.google.com URLs through the r.jina.ai reader
proxy (`https://r.jina.ai/<google-patents-url>`), which returns the
server-rendered page content. Each record's Source URL field points to the
canonical patents.google.com page for independent re-verification.
